# Development

Use the root README for current standalone build and validation commands.
Implementation is Kotlin-native; do not add Python to Gradle or JVM tests.
Make material changes through the explicit snapshot process in data/README.md.

Preserve numerical laws, stored-rig compatibility, physical topology and the
current demonstration restrictions. Feature work requires its own approved scope.
Historical milestones in doc_archive are read-only context. Tests under
app/src/test include analytical cases, finite differences, material fingerprints,
saved rigs, catalogue reproduction and the checked-in Python reference evidence.

Keep private phone backups, exports and temporary test results outside Git.
validation only permits the reviewed migration audit/results documents by default.
The original project's historical validation records remain there, including all
personal data. No device data was copied, cleared or installed by this migration.
